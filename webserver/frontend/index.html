API Reference

POST /rangeproof/generate

Generate a rangeproof for a given value.

Request Body:

{
  "value": 100,
  "bits": 64
}

Response:

{
  "commitment": "...",
  "proof": "..."
}

POST /rangeproof/verify

Verify a rangeproof.

Request Body:

{
  "commitment": "...",
  "proof": "..."
}

Response:

{
  "valid": true
}

POST /nullifier/generate

Generate a nullifier hash from a user secret.

Request Body:

{
  "user_secret": "your_secret",
  "scope": "poh/v1"
}

Response:

{
  "nullifier": "..."
}

POST /nullifier/verify

Verify a nullifier against its input.

Request Body:

{
  "input": "some_input",
  "nullifier": "..."
}

Response:

{
  "valid": true
}

POST /nullifier/register

Register a nullifier in the registry.

Request Body:

{
  "nullifier": "...",
  "scope": "poh/v1"
}

Response:

{
  "registered": true,
  "message": "..."
}
